Substitution: fortune recognition and story generation use the language model of the workshop LLM bridge (shown at the top right), prompted with the paper's fortune definition and calibration sentences. The paper used GPT-Neo 2.7B with trained soft prompts and a GeDi control model (GPT2-medium), which are not available here. The surprise level is given to the model in words, because the bridge has no temperature setting. Remix, not in the paper: "+ Character" adds up to three more characters, each with its own fortune line, the Relationships panel sets how each pair of characters gets along, from conflict to harmony, and the Writing model menu chooses the Claude model that writes the sentences (ratings stay with the main bridge's model).
