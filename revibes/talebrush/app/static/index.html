A STORY, ONE STROKE AT A TIME

Give the story a little direction.

  1. Set the scene. Add named characters with roles/goals, choose a character and story dimension, and write a sentence or two on the left. One row is one step in the story.
  2. Sketch what happens. Draw across empty sentence positions. The axis labels define high and low for the selected dimension. Each character/dimension has its own curve, and generation combines all drawn curves. Release to generate. Slow strokes narrow the green envelope and consider more candidate sentences.
  3. Follow the blue line. Generated sentences are independently scored for the selected and drawn character/dimension pairs and plotted over your sketch. Hover over a sentence or point to connect them. Blank sentences appear as gaps.
  4. Try another direction. Redraw a section to replace only that section’s AI sentences. Generate Again repeats the last range. Your own words are kept as fixed anchors; clear a row to let AI replace it.
  5. Leave some space. Erase part of the selected sketch, then Generate Again to release that constraint while keeping the other curves. To infill, write an ending after some blank rows and sketch between the anchors.
  6. Keep the possibilities. Open History to overlay past arcs, hover or focus a draft to preview it, and select to restore it. Drafts and history are saved in this browser.
About the paper and model substitutions

Remixed from Chung et al., “TaleBrush: Sketching Stories with Generative Pretrained Language Models,” CHI 2022, DOI 10.1145/3491102.3501819.

The original uses soft-prompt-tuned GPT-Neo 2.7B for recognition and generation, and modified GeDi with GPT2-medium for continuous fortune control. This reconstruction uses prompt-based generation and separate recognition calls through the workshop’s signed-in Codex bridge. It does not reproduce training or claim equivalent model quality.

Multiple characters, mood, confidence, tension and custom dimensions extend the original paper. All drawn targets guide generation together. Candidate sentences are generated in one batch and independently scored in a second call. If the first candidate differs from any target by more than 0.2, the candidate with the smallest aggregate error across constrained pairs is selected; narrower tolerances carry more weight. Scores use the preceding context’s first candidates, so chosen alternatives can slightly change context. Infilling uses both fixed contexts in a single pass rather than alternating directions. Surprise is expressed as an instruction because the bridge ignores temperature. Pointer speed determines tolerance; its numeric calibration is a reconstruction choice.

Analyze arcs scores the selected and drawn character/dimension pairs in your existing text. Custom dimensions use the low/high meanings you supply. Up to six characters and eight dimensions are supported. Generation and analysis use your Codex plan. No API key is required, and failures never silently switch to canned stories.
